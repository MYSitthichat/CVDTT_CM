# คำแนะนำการสร้าง Word Template สำหรับฟอร์ม Parasite

## Placeholders ที่ใช้ในระบบ

ในไฟล์ Word template คุณต้องใส่ placeholders ตามตำแหน่งที่ต้องการให้ระบบเติมข้อมูลอัตโนมัติ

### รายการ Placeholders

```
{{เลขที่รายงาน}}      - เลขที่รายงานจาก report_form.id
{{เลขที่ตัวอย่าง}}     - รูปแบบ D{day}-{lab_order_id} เช่น D22-1601
{{วันที่รับตัวอย่าง}}   - วันที่จาก case_registration.dtime
{{Color}}             - สีที่เลือกจาก dropdown (สำหรับ Faces เท่านั้น)
{{Consistency}}       - ความเหนียวที่เลือก (สำหรับ Faces เท่านั้น)
{{Method}}            - วิธีการตรวจที่เลือก (สำหรับ Faces เท่านั้น)
```

## วิธีการใส่ Placeholders ใน Word

### 1. ในส่วนหัวฟอร์ม (Header Section)

ตัวอย่าง:
```
เลขที่รายงาน: {{เลขที่รายงาน}}
เลขที่ตัวอย่าง: {{เลขที่ตัวอย่าง}}
วันที่รับตัวอย่าง: {{วันที่รับตัวอย่าง}}
```

### 2. ในตาราง (Table)

ตัวอย่างตารางสำหรับ Faces:

| Feces characteristics |           |              |  
|----------------------|-----------|--------------|
| Color                | {{Color}} |              |
| Consistency          | {{Consistency}} |        |
| Method               | {{Method}} |             |

### 3. ข้อควรระวัง

- ใช้วงเล็บปีกกา `{{` และ `}}` ครอบคำ placeholder
- **ห้าม** เว้นวรรคภายใน placeholder เช่น `{{ เลขที่รายงาน }}` จะไม่ทำงาน
- ใช้ชื่อ placeholder **ตรงตาม** ที่กำหนดไว้ (case-sensitive)
- สามารถใส่ placeholder ได้ทั้งใน paragraph และ table cell

## ขั้นตอนการสร้าง Template

1. เปิด Microsoft Word
2. สร้างโครงสร้างฟอร์มตามต้องการ
3. ใส่ placeholder ในตำแหน่งที่ต้องการให้ระบบเติมข้อมูล
4. บันทึกไฟล์เป็น .docx
5. อัพโหลดไฟล์ไปยัง `BACKEND/report_template/word/`
6. เพิ่มข้อมูลไฟล์ใน table `report_information`

## การทดสอบ Template

1. วางไฟล์ template ในโฟลเดอร์ที่กำหนด
2. เพิ่มข้อมูลใน database
3. เลือกเคสและฟอร์มในระบบ
4. กดปุ่ม "FORM PREVIEW"
5. ตรวจสอบว่าข้อมูลถูกเติมถูกต้องครบถ้วน
6. กดปุ่ม "บันทึก" เพื่อทดสอบการบันทึกไฟล์

## การแก้ไขปัญหา

### ปัญหา: ข้อมูลไม่ถูกแทนที่
- ตรวจสอบว่า placeholder สะกดถูกต้อง
- ตรวจสอบว่าไม่มีเว้นวรรคภายใน `{{ }}`
- ตรวจสอบว่าใช้วงเล็บปีกกา `{{` และ `}}` ไม่ใช่ `{` และ `}`

### ปัญหา: Font หายหรือเพี้ยน
- ตรวจสอบว่าติดตั้ง font ที่ใช้ในเครื่องแล้ว
- ใช้ font ที่รองรับภาษาไทย

### ปัญหา: Format เพี้ยนหลังแทนที่
- อาจเกิดจากการใช้ text box หรือ shapes
- แนะนำให้ใช้ paragraph และ table ธรรมดาแทน
